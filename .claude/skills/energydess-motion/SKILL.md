# Анимации залогиненной части energydess.ru

Утверждено владельцем 2026-10-03 (письмо M1, BACKLOG №384) по демо из трёх
стилей. Этот скилл ГЛАВНЕЕ сторонних (`animate`, `review-animations`,
`improve-animations`, `impeccable`, `taste-skill` — см. `../VENDOR.md`):
их советы годятся, пока не спорят с токенами и запретами ниже.

## Оглавление

1. Когда применять

## 1. Когда применять

Любая работа с интерфейсом ЗАЛОГИНЕННОЙ части: страницы инструментов,
админка, «Контент», профиль. Незалогиненная главная (лендинг-портфолио,
`templates/landing.html`, `static/landing.*`) — ВНЕ этого скилла и вне
примитивов: у неё свои анимации, и трогать их здесь нельзя.

Примитивы подключены там же, где каркас v2 (`templates/_meta.html`
и `templates/_page_end.html`, условие «вошёл с подтверждённой почтой,
не `header_pf`, не `shell_off`»), — лендинг их не грузит.

## 2. Жёсткие запреты

1. **Лендинг не трогается**: ни его шаблоны, ни CSS/JS, ни общие файлы
   вне условного блока каркаса.
2. **Никаких глобальных селекторов** для анимаций: `*`, `button`, `a`,
   `input`, `[class*=…]`. Движение включается только явным классом
   (`.m-*`) или вызовом `Motion.*` на конкретном элементе.
3. Анимируются только `transform`, `opacity`, `filter`. Высота — только
   у раскрытия и схлопывания блока (рецепт ниже), и только там.
4. `prefers-reduced-motion: reduce`: длительности почти ноль, допустимо
   лишь короткое проявление opacity ≤ 120 мс. Примитивы делают это сами.
5. **Контент виден в покое.** Ни один элемент не ждёт JS или наблюдателя
   прокрутки в `opacity: 0`. Начальное состояние появления задаёт сам
   вызов анимации (WAAPI `fill: backwards`), а не CSS: не загрузился
   скрипт — всё видно.
6. **Пружинка (overshoot) — только у объектов**: карточки, кнопки, плашки,
   тосты. Никогда у текста, строк и цифр.

## 3. Три характера и токены

Токены объявлены ОДИН раз — `:root` в `static/motion.css`; `motion.js`
читает их оттуда же (`getComputedStyle`), второго источника чисел нет.

**Живой** — объекты (`--m-live-*`)

| токен | значение |
|---|---|
| fast / base / slow | 160 / 280 / 440 мс |
| ease | `cubic-bezier(.22,1,.36,1)` |
| pop (пружинка) | `cubic-bezier(.34,1.56,.64,1)` |
| stagger | 55 мс |
| сдвиг появления | 14px |
| scale с | .95 |
| hover | подъём −5px, scale 1.015 |
| нажатие | scale .95 |

**Мягкий** — текст, цифры, загрузка, переключатели (`--m-soft-*`)

| токен | значение |
|---|---|
| fast / base / slow | 180 / 320 / 520 мс |
| ease | `cubic-bezier(.22,1,.36,1)`, без отскока |
| stagger | 50 мс |
| сдвиг | 10px |
| scale с | .99 |
| проявление из blur | 4px |
| счётчик | 950 мс, easeOutCubic, без перелёта за итог |

**Кино** — только главные моменты (`--m-cine-*`)

| токен | значение |
|---|---|
| fast / base / slow | 220 / 480 / 760 мс |
| ease | `cubic-bezier(.16,1,.3,1)` |
| stagger | 90 мс |
| сдвиг | 22px |
| blur | 10px |
| шаг этапа | 480 мс |
| блик (sheen) | проход 1100 мс |
| свечение-пульс | 1600 мс |

**Уход (exit)** во всех характерах: длительность fast своего характера,
ease `cubic-bezier(.4,0,1,1)` (`--m-exit-ease`).
**Схлопывание места** после ухода (`leave`): кривая `--m-collapse-ease`
`cubic-bezier(.45,0,.3,1)` без крутого начала, длительность — не меньше
base и растёт с высотой: за кадр место уходит не больше ~24 px (письмо
M1b — кривая «Живого» отдавала 56 px за кадр у строки в 130 px).

## 4. Таблица «элемент → характер → рецепт»

| Элемент | Характер | Рецепт |
|---|---|---|
| Появление списков и карточек | Живой | `Motion.enter(список, 'live')` — волна по очереди |
| Переключатели («Длинные / Shorts» и т. п.) | Мягкий | `.m-seg` — плашка едет без отскока; список — `Motion.swap(контейнер, html, 'soft')`: старое уходит, новое волной, высота без скачка |
| Наведение и нажатие | Живой | `.m-hover-lift`, `.m-press` |
| Раскрытие блоков | Живой | `.m-collapse` (`grid-template-rows: 0fr→1fr`), пункты — `Motion.enter` |
| Удаление элемента из списка | Живой | `Motion.leave(el)` — уход, затем схлопывание места без скачка |
| Цифры и шкалы | Мягкий | `Motion.countUp(el, to, decimals)`; шкала — `transform: scaleX` без отскока |
| Сборка пакета (этапы и готовность) | Кино | `Motion.buildStep(этап)` — зажигается со свечением; `Motion.buildDone(результат)` — проявление из blur и блик |
| Уведомления (toast) | Живой | `Motion.toast(текст)` — выезжает снизу с пружинкой, уходит быстро |
| Загрузка (скелетоны) | Мягкий | `.m-skeleton` — мерцание; содержимое — `Motion.enter(…, 'soft')` (из blur волной) |
| Переходы между экранами | Живой | сдвиг по горизонтали с пружинкой (пока не применён нигде — отдельным письмом) |

## 5. Примитивы

`static/motion.css` (подключение через `{{ st('motion.css') }}`):

- `.m-hover-lift` — подъём и scale при наведении (только `@media (hover: hover)`);
- `.m-press` — scale .95 при нажатии;
- `.m-seg` + дочерний `.m-seg-pill` — переключатель с едущей плашкой;
  позицию ставит `Motion.seg(контейнер, кнопка)`;
- `.m-collapse` > `.m-collapse-inner` — раскрытие; открыт при `.is-open`;
- `.m-skeleton` — мерцание скелета (полоса едет `transform`);
- блок `prefers-reduced-motion`.

`static/motion.js` — `window.Motion`, без библиотек, Web Animations API:

| функция | что делает |
|---|---|
| `enter(els, ch='live')` | волна появления; `ch`: `live` / `soft` / `cine` |
| `leave(el, ch='live')` | уход и схлопывание места; возвращает Promise, удаляет элемент |
| `swap(container, change, ch='soft', {items})` | `change` — строка HTML либо функция `change(корень)`, меняющая DOM внутри корня; высота меряется заранее на невидимом клоне и едет одновременно с уходом → вставка → появление волной → фиксация снимается |
| `seg(container, btn)` | двигает плашку `.m-seg-pill` под кнопку |
| `countUp(el, to, decimals=0, from=0)` | счётчик без перелёта; `from` — обновление на месте (3 → 4) |
| `toast(text)` | уведомление снизу |
| `buildStep(stepEl)`, `buildDone(resultEl)` | «Кино» для сборки пакета |
| `reduced()` | `true`, если пользователь просит меньше движения |

Все функции ничего не делают, если элемента нет, и уважают reduced-motion.

## 6. Рецепты

**Появление без «невидимого покоя».** Ключевые кадры появления идут
с `fill: 'backwards'`: состояние «до» действует только на время задержки
волны, а после анимации остаётся то, что задано в CSS (видимое). Не писать
`opacity: 0` в CSS ради «потом покажем».

**Замена списка без мигания (`swap`).** Новая высота меряется заранее:
клон контейнера той же ширины, невидимый и вне потока, получает новое
состояние, с него снимается высота. Дальше высота контейнера едет от
старой к новой (base) ОДНОВРЕМЕННО с уходом старых пунктов (fast,
exit-ease); затем вставка и волна появления; явная высота снимается.
Контейнер НИКОГДА не схлопывается в 0, а всё движение раскладки
укладывается в base — то есть в 500 мс после нажатия, где сдвиги
не считаются в CLS. Поэтому `change` — функция от КОРНЯ: swap зовёт её
дважды, на клоне и на настоящем контейнере.

**Раскрытие.** `display: grid; grid-template-rows: 0fr` → `1fr` при
`.is-open`, ребёнок `min-height: 0; overflow: hidden`. Пункты внутри —
`Motion.enter` после открытия.

**Пружинка.** `--m-live-pop` — только у объекта целиком (карточка, плашка,
тост). Текст внутри едет вместе с объектом, своего отскока не имеет.

**Счётчик.** `easeOutCubic`, значение `Math.min(итог, …)` — перелёт
невозможен по построению; итог ставится точным числом в последнем кадре.

## 7. Проверка плавности

`py check_motion.py` — проба плавности на «Сегодня» модуля «Контент»
(1920 и 390): кадры длиннее 50 мс — не больше одного на действие, CLS
при переключении 0, контейнер не схлопывается в 0, при reduced-motion
анимации ≤ 120 мс. `--контроль` снимает фиксацию высоты в `swap`
и обязан покраснеть. Новый экран с анимациями — дописать его действия
в пробу тем же образцом.

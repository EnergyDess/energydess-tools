# Пополняется правкой этого файла.
#
# Формат тот же, что у `hh_letter_phrases.txt`: строка `[раздел]`, под ней
# регулярные выражения Python, по одному на строку, без учёта регистра.
#
# Технология ВНЕ досье и резюме разбирается по месту упоминания:
#   отрицание  — в том же отрезке (до запятой, точки с запятой, точки)
#                стоит отрицание: «с PostgreSQL не работал». НЕ находка;
#   требование — отрезок или предложение называют стек либо требования
#                вакансии: «у вас Git». НЕ находка, если технология есть
#                в тексте вакансии; НАХОДКА, если её там нет (выдумано
#                требование);
#   опыт       — отрезок либо предложение говорят от первого лица о своей
#                работе: «работаю с Groq». НАХОДКА;
#   ничего не подошло — СПОРНОЕ: печатается пробой 44, в журнал прода
#                не пишется (лучше промолчать, чем засорить счётчик).
